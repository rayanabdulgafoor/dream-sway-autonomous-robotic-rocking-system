## Overview

Dream Sway is an autonomous robotic rocking system developed to study controlled oscillatory motion, dynamic stability, and human-interactive motion regulation. The system combines embedded sensing, feedback control, and mechanical actuation to maintain smooth rocking behavior under varying load conditions.

The project explores closed-loop motion control using IMU-based orientation sensing, PID stabilization, and dynamic center-of-gravity adjustment through a custom mass-shifting mechanism.

---

## Key Features

* Autonomous rocking motion regulation
* IMU-based orientation sensing
* Closed-loop PID stabilization
* Dynamic center-of-gravity adjustment
* Electromechanical motion control architecture
* Stability and damping behavior analysis
* Load-tested up to 130 kg
* Manual and automated validation workflows
